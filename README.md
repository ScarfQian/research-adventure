# 科研大冒险

日期：2026-10-27  
创建人：ScarfQian

从小学启程，在考试、专业选择、研究课题与学术生涯中构筑属于自己的成长路线。这是一个独立的肉鸽游戏项目，当前版本 **0.0.1：设计与项目初始化**，尚无可运行的游戏。

## 核心规则

- 小学作为开场与教学，第一张正式地图暂定为「初中大冒险」。这是为协调“小学起步”和“第一关初中”的设计提案。
- 每个正式关卡代表一个成长阶段。通关后打开卷轴路线地图，选择当前阶段连接的下一站。
- 每局重新出发都从第一关开始。永久解锁的是后续路线资格，不是从营地直接进入高阶段的权限。
- 初中失利显示「中考失利」，可重新开局，或进入本局的中专／职高隐藏路线。
- 高中通关后可选择本科或大专；这项选择只在本局再次通关高中时出现。
- 局内卡片改变攻击方式、学习方法及资源循环；阶段之间保留构筑，整局结束时清零。
- 后期包含科研项目卡与人才荣誉卡。「博新计划、国自然、国社科、优青、杰青、长江」用于游戏题材设计，游戏触发条件不代表现实申请规则。
